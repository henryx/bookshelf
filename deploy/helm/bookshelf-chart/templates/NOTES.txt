Bookshelf {{ .Chart.AppVersion }} is installed as {{ include "bookshelf.fullname" . }} in {{ .Release.Namespace }}.

The setup wizard (/setup) asks for a setup token; get it with:

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "bookshelf.fullname" . }} -- \
    /app/venv/bin/flask --app bookshelf setup-token

or create the first admin from the CLI instead:

  kubectl -n {{ .Release.Namespace }} exec -it deploy/{{ include "bookshelf.fullname" . }} -- \
    /app/venv/bin/flask --app bookshelf create-admin admin@example.com
{{- if .Values.ingress.enabled }}

Then open https://{{ .Values.ingress.host }}/
{{- else }}

No Ingress is enabled (ingress.enabled). To try it locally:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "bookshelf.fullname" . }} 8080:{{ .Values.service.port }}

and open http://localhost:8080/
{{- end }}
